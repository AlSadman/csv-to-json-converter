# Demo Data Directory

This directory contains sample CSV files for demonstration, testing, and validation of the CSV to JSON Converter.

Files included:
- `employees.csv` - Basic employee records.
- `products.csv` - Product inventory data with numeric fields for auto-type conversion testing.
- `unicode_data.csv` - Multilingual records containing Unicode characters (Bangla, Arabic, English).
- `empty.csv` - A completely empty file for zero-byte edge case validation.
